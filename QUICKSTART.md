# NQ London Session Backtest - Quick Start Guide

## Run the Analysis in 3 Steps

### Step 1: Install Dependencies (First Time Only)

```bash
pip install -r requirements_backtest.txt
```

### Step 2: Run the Backtest

```bash
python3 nq_london_session_backtest.py
```

Or use the convenience script:

```bash
./run_backtest.sh
```

### Step 3: Review Results

Open `nq_analysis_results.txt` to see the complete analysis summary.
