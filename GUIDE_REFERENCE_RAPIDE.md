# Guide de Référence Rapide - Tokyo-London Killzone Strategy

## 🎯 Checklist Pre-Trade (À IMPRIMER)

### Phase 1: Préparation (Avant 19h00 EST)
```
□ Identifier le Daily Bias (structure de marché 4H/Daily)
□ Marquer les niveaux de liquidité clés (highs/lows récents)
□ Déterminer si le prix est en Premium ou Discount
□ Vérifier le calendrier économique (éviter NFP/FOMC)
```

### Phase 2: Surveillance Asiatique (19h00 - 23h00 EST)
```
□ Tracer le haut du range asiatique (Asian High)
□ Tracer le bas du range asiatique (Asian Low)
□ Noter la taille du range (doit être significatif)
□ Identifier les Liquidity Pools (au-dessus et en dessous)
```

### Phase 3: London Open (01h00 - 05h00 EST)
```
□ Observer sans trader immédiatement
□ Attendre le Liquidity Sweep du range asiatique
□ Confirmer le reversal (Market Structure Shift)
□ Identifier l'Order Block ou Fair Value Gap
□ Valider l'entrée en zone Discount (si bias haussier)
□ Calculer le ratio R:R (minimum 1:3)
```

### Phase 4: Exécution
```
□ Placer l'entrée dans la zone d'intérêt
□ Stop Loss: en dessous du sweep low (ou au-dessus du sweep high)
□ Take Profit: Liquidité opposée du range asiatique
□ Risque: Maximum 1-2% du capital
□ Confirmer: Minimum 3/5 critères de validation remplis
```

---

## 📊 Les 5 Critères de Validation ICT

Un setup est VALIDE si **au minimum 3 sur 5** sont remplis :

1. ✅ **Daily Bias Confirmé**
   - Structure haussière sur 4H/Daily OU
   - Structure baissière sur 4H/Daily

2. ✅ **Liquidity Sweep Clair**
   - Cassure du Asian High (pour short) OU
   - Cassure du Asian Low (pour long)
   - Avec volume et reversal rapide

3. ✅ **Market Structure Shift (MSS)**
   - Cassure d'un high interne (pour long)
   - Cassure d'un low interne (pour short)

4. ✅ **Order Block OU Fair Value Gap**
   - Zone d'entrée clairement identifiée
   - Confluence avec niveaux clés

5. ✅ **Ratio R:R ≥ 1:3**
   - Target mesurée vers liquidité opposée
   - Stop serré sous sweep

## 🚫 Quand NE PAS Trader

### Jours à Éviter
- ❌ Lundi (liquidité limitée post-weekend)
- ❌ Vendredi après-midi (profit-taking, early close)
- ❌ Jours fériés US/UK
- ❌ Jours de NFP (Non-Farm Payrolls)
- ❌ Jours de FOMC (Federal Reserve meetings)

### Conditions de Marché Défavorables
- ❌ Range asiatique trop petit (< 10 points ES)
- ❌ Pas de Daily Bias clair
- ❌ Prix en Premium avec bias haussier (ou inverse)
- ❌ Ratio R:R < 1:2
- ❌ Moins de 3 critères de validation remplis

## 💰 Gestion de Position - Plan d'Action

### Entrée
- **Type**: Limite (dans la zone Order Block / FVG)
- **Taille**: 1% de risque maximum
- **Confirmation**: Attendre le retracement après MSS

### Gestion des Profits
```
TP1 (30% de la position): Haut/Bas du range asiatique
→ Déplacer le stop au breakeven

TP2 (40% de la position): Liquidité opposée (+1-2%)
→ Trail stop avec Order Blocks mineurs

TP3 (30% de la position): Extension ou PDH/PDL
→ Laisser courir ou sortie avant 08h00 EST
```

### Stop Loss
- **Placement**: 2-3 points en dessous du sweep low (ou au-dessus du sweep high)
- **Jamais déplacer** le stop dans la mauvaise direction
- **Accepter la perte** si le stop est touché (fait partie de la stratégie)

## 📈 Statistiques Réalistes

### Win Rate Attendu
```
✅ Backtest rigoureux: 40-55%
❌ Marketing hype:     80-95% (irréaliste)
```

### Ratio R:R Moyen
```
✅ Target réaliste:  1:3 à 1:5
⚠️  Minimum requis:  1:2
❌ Sous 1:2:        Setup invalide
```

### Expectancy (Espérance Mathématique)
```
Formule: (Win% × Avg Win) - (Loss% × Avg Loss)

Exemple avec Win Rate 45%, R:R 1:3:
= (0.45 × 3) - (0.55 × 1)
= 1.35 - 0.55
= +0.80 (Expectancy positive ✅)
```

## 🎓 Exemples de Setups

### Exemple 1: Setup Haussier (Bias Haussier)

**Contexte:**
- Daily: Structure haussière (Higher Highs, Higher Lows)
- Asian Range: 4500 - 4510

**Exécution:**
1. London sweep → 4498 (casse 4500) ✅
2. Reversal rapide → MSS confirmé ✅
3. FVG identifié: 4502-4505 ✅
4. Entrée: 4503 (dans le FVG)
5. Stop: 4496 (sous sweep)
6. Target: 4515 (BSL au-dessus du range)
7. R:R: 12/7 = 1:1.7 ⚠️ (acceptable mais pas optimal)

### Exemple 2: Setup Baissier (Bias Baissier)

**Contexte:**
- Daily: Structure baissière (Lower Lows, Lower Highs)
- Asian Range: 4600 - 4610

**Exécution:**
1. London sweep → 4612 (casse 4610) ✅
2. Reversal baissier → MSS confirmé ✅
3. Order Block identifié: 4608-4610 ✅
4. Entrée: 4609 (dans l'OB)
5. Stop: 4614 (au-dessus sweep)
6. Target: 4598 (SSL en dessous du range)
7. R:R: 11/5 = 1:2.2 ✅ (bon setup)

## ⚡ Actions Rapides pour Traders

### Avant de Dormir (18h00 EST)
1. Check Daily Bias (5 minutes)
2. Marquer les niveaux clés sur le graphique
3. Placer des alertes sur Asian High/Low potentiels

### Au Réveil (00h30 EST)
1. Observer le range asiatique formé
2. Attendre London Open avec patience
3. NE PAS anticiper le sweep

### Pendant London Open (01h00 - 03h00 EST)
1. Observer le sweep
2. Attendre le MSS
3. Entrer sur le retracement
4. Gérer la position selon le plan

### Fin de Session (05h00 - 08h00 EST)
1. Sécuriser les profits partiels
2. Trail stop si en profit
3. Accepter le résultat sans émotion
