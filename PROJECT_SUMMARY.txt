================================================================================
STRATEGY IMPLEMENTATION
================================================================================

✓ FVG Detection
  - Bullish FVG: High[i-2] < Low[i]
  - Bearish FVG: Low[i-2] > High[i]

✓ Consequent Encroachment Calculation
  - Long C.E. = (High[i-2] + Low[i]) / 2
  - Short C.E. = (Low[i-2] + High[i]) / 2

✓ Limit Order Entry Simulation
  - Entry triggered when price touches C.E. level
  - Precise execution at C.E. price (not close)
  - Only during trading session (01:00-05:00)

✓ Setup Cancellation
  - Automatically invalidates if SL broken before entry
  - Uses forward-fill (ffill) for level propagation

✓ Three Risk Models Implemented
  1. Aggressive Sniper (FVG border-based, 3:1 R:R)
  2. Structural Defender (swing candle-based, fixed TP)
  3. Volatility Adapter (ATR-based, dynamic risk)

✓ Exit Management
  - Stop Loss based on risk model
  - Take Profit based on risk model
  - Hard exit at 08:00 (closes at Close price)
